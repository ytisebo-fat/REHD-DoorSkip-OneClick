# Publish on GitHub (first time)

1. Create a free account at https://github.com/ if you don't have one, and sign in.
2. Open https://github.com/new.
3. Set **Repository name** to `REHD-DoorSkip-OneClick`, choose **Public** if you want to share it with everyone, and click **Create repository**. Do not tick **Add a README** (the project already has one).
4. In your new empty repository, click **uploading an existing file** (or **Add file → Upload files**).
5. **Extract this ZIP on your computer**, then drag its contents into GitHub's upload area: all four scripts, `README.md`, `.gitignore`, and `PUBLISHING-GUIDE.md`. Do *not* upload the ZIP instead of the individual files.
6. Click **Commit changes**. Your repository is now published.

Your public project URL will be `https://github.com/YOUR-USERNAME/REHD-DoorSkip-OneClick`.

To share a downloadable package later, visitors can choose **Code → Download ZIP**. GitHub Releases can also provide separately packaged downloads.

**Never upload `bhd.exe`, saved games, personal diagnostic reports, or copyrighted game files.**
